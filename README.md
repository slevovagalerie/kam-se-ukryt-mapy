# Mapy pro appku Kam se ukrýt

Offline mapy krajů České republiky pro Android appku **Kam se ukrýt** (nejbližší úkryt a co dělat při poplachu).

- Formát: [PMTiles](https://github.com/protomaps/PMTiles), vektorové dlaždice do zoomu 15.
- Každý měsíc je automaticky vyrobí workflow [Mapy](.github/workflows/mapy.yml) a zveřejní jako nové vydání.
- Nejnovější soubory: `https://github.com/slevovagalerie/kam-se-ukryt-mapy/releases/latest/download/{kod}.pmtiles`, seznam krajů s velikostmi v `index.json`.
